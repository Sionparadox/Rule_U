# RAG 부족 시 BGG 추가 조회

2026-10-22 사용자 요청으로 구현.

## 동작

- 로컬 검색 결과가 없거나, 유효한 모델 응답이 `insufficient_evidence`이면 한 번만 BGG를 조회한다. 충분한 답변·추가 질문·잘못된 모델 JSON은 조회 사유가 아니다.
- 명시적 BGG 외부 ID를 우선한다. 로컬 카탈로그 번호는 BGG ID로 쓰지 않는다. 없는 경우 원제의 정확한 이름 검색을 사용하고, 일치 게임이 여러 개거나 없으면 추측하지 않는다.
- 해당 게임의 Rules 포럼 첫 페이지(최근 게시물 최대 50개)에서 질문·판본·확장을 고려해 모델이 후보 최대 2개를 선택한다. 후보 목록 밖 ID는 거부한다. 각 스레드 첫 10개 게시물만 확인하며 답글이 없는 질문은 근거로 쓰지 않는다. 전체 BGG 검색이나 전체 스레드 열람이 아니다.
- XML 응답은 24시간 캐시하고 단일 API 서버 이벤트 루프에서 요청 시작 간격을 최소 5초로 제한한다. HTTP 요청당 8초, 전체 BGG 과정 기본 45초, XML 응답 1MB 제한. 자동 HTTP 재시도·리다이렉트·임의 URL 접근은 하지 않는다. 다중 API 프로세스 간 전역 제한은 별도 구현하지 않았다.
- BGG 글은 `bgg_community` 문서 스냅샷으로 저장한다. Chroma에 공식 룰북으로 색인하지 않는다. 인용 번호는 로컬 근거 뒤에 붙이고 기존 세션 소유권 검사와 인용 복원을 유지한다.
- 모델에 판본·확장 호환성 확인, 공식 규칙 우선, 충돌·관련성 부족 시 보류를 지시한다. BGG를 인용하면 서버가 공식 판정이 아니라는 문구와 `conditional` 표시를 적용한다. 의미적 정확성·판본 호환성을 코드가 자동 보증하지는 않는다.
- 모달에는 커뮤니티 표시·관련 내용 요약·적용 이유·토론 링크를 보여준다. 원시 청크·검색 점수는 화면에 표시하지 않으며 로컬 룰북 다운로드를 제공하지 않는다.
- 서버 `bgg` 단계에 스피너 문구를 연결했다. 토큰 누락·인증 거부·동일 게임 식별 실패·관련 토론 없음·연결 실패를 구분한다. 실패해도 근거 부족 답변을 저장한다.

## 설정

루트 `.env`에 아래를 설정하고 API 서버를 재시작한다. 기존 채팅·임베딩 설정은 유지한다.

```dotenv
BGG_ENABLED=true
BGG_API_TOKEN=승인된_애플리케이션_토큰
BGG_TIMEOUT_SECONDS=45
```

`CHAT_PROVIDER=compatible`에서 동작한다. mock 모드는 네트워크를 호출하지 않는다. API 토큰은 서버 전용이며 NEXT_PUBLIC 변수·로그·응답에 노출하지 않는다. 앱 등록·승인과 토큰 발급은 [BGG 안내](https://boardgamegeek.com/using_the_xml_api)를 따른다. 사용 엔드포인트는 [XML API2 명세](https://boardgamegeek.com/wiki/page/bgg_xml_api2)의 search, forumlist, forum, thread다. 공개 배포는 이번 범위가 아니며 배포 시 BGG 표시·이용 조건을 확인해야 한다.

## 검증

- 전체 pytest 62개 통과 후, 잘못된 모델 JSON을 조회 사유에서 제외하는 최종 수정 및 추가 테스트를 포함한 관련 테스트 29개 통과.
- HTTP 대체 응답으로 Bearer 인증 헤더, 로컬 ID 혼동 방지, 정확한 게임 식별, XML/인증/429/202 거부, 캐시 재사용, 커뮤니티 출처 저장을 검증했다.
- RAG 있음/없음의 추가 조회, 한 번만 호출, 번호 유지, 충분한 근거·추가 질문 시 미호출, 연결 실패 시 보류, 세션 간 출처·설명 접근 차단, 중복 전송을 검증했다.
- Playwright 모바일·데스크톱 20개 통과. BGG 모달 표시·룰북 오인 방지·원문 미노출과 기존 탐색·대화·복원·재시도 회귀를 검증했다. 브라우저 BGG 출처는 라우트 대체 응답으로 검증했다.
- TypeScript, ESLint, Prettier 검사, Ruff, Playwright 준비 단계의 Next.js 프로덕션 빌드 통과.
- 현재 로컬 BGG 토큰 미설정. 실제 BGG 통신 및 실제 모델의 영어 토론 선택·규칙 해석 품질은 검증하지 않았다. 자동 테스트는 대체 모델/XML 응답이다.
