# 게임 선택 화면 상단 정리

2026-10-22. 사용자 요청에 따라 설치된 frontend-design 스킬을 적용했다.

방향: 게임 카드가 시각적 중심이 되도록 상단은 왼쪽 정렬의 로고 → 제목·안내 → 검색 → 접이식 조건으로 구성한다. 별도 히어로 일러스트나 인사말은 사용하지 않는다.

기존 색을 유지한다: 배경 #EDF8F5, 표면 #FFFFFF, 본문 #173E39, 주요 동작 #087F70, 구분선 #D3E9E3. Pretendard를 유지하고 제목은 모바일 24px·데스크톱 30px, 안내는 14px로 정리했다. 하단 게임 카드의 구조·그림·색상은 변경하지 않았다.

변경: 기울어진 상단 일러스트·별 장식·인사말 제거, 로고 정렬, 검색창 그림자 제거, 필터를 간결한 펼침 행으로 변경, 최근 대화를 텍스트 중심의 이어하기 행으로 변경했다. 기능·키보드 포커스·44px 이상 터치 영역을 유지했다.

검토: 360px와 1440px 캡처에서 상단 위계와 게임 카드 연결을 육안 확인했다. 360/768/1440px 가로 넘침 검사는 기존 Playwright 시나리오로 확인한다. 테스트 자료는 가상 게임이다.
