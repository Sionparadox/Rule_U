# 이미지 규칙서 복원 (2026-10-22)

기존 실패 49개 게임, 50개 PDF에서 검토 대상으로 지정된 174쪽을 이미지로 확인했다. 규칙 146쪽과 도해 3쪽은 정리 전사했고, 표지 18쪽·삽화 2쪽·다른 언어 2쪽·판권 1쪽·광고 1쪽·빈 카드 양식 1쪽은 제외 사유를 남겼다. 다른 언어 페이지 제외는 한국어 수집 범위에 따른 결정이다.

복원문은 원문을 그대로 옮긴 완전 전사가 아니라 이미지 확인 후 작성한 규칙 요약이다. Windows OCR 초안은 그대로 수집하지 않았다. 세부 표현이나 표 전체가 필요한 답변은 원본 PDF를 다시 확인해야 한다. 하이브 PDF 3쪽(여왕벌 배치 전 이동)과 8쪽(딱정벌레에 덮인 모기)에는 원문 간 모순을 주석으로 보존했다. 이러한 문장을 확정 규칙으로 사용하면 안 된다.

`data/retry-reports/vision/reviewed-pages.json`은 원래 수집 범위 ID에 연결된 검토 기록이다. 이를 카탈로그의 원본 SHA-256에 연결한 `reviewed-bound.json`을 수집 입력으로 사용한다. 원본 PDF는 변경하지 않았다. 검토 이미지 해시, 실제 PDF 페이지 번호, 제외 사유를 추출 산출물에 보존한다. 청크의 오프셋은 복원된 텍스트 기준이며 원본 PDF 문자 오프셋이 아니다.

49개 게임을 재수집한 결과 51개 문서가 성공했다. 이 수치는 기존에 성공했던 문서 1개를 포함하며, 기존 실패 PDF는 50개다. 해당 게임의 청크는 총 1,060개다. 청킹 설정은 기존 1,000자 / 200자 중첩을 유지했다.

CLI `ingest --reviewed-pages <reviewed-bound.json> --pdf-extractor pymupdf`로 복원문을 적용할 수 있다. `--games`로 복원한 49개 게임만 선택하여 기존 61개 게임의 추출 결과를 보존했다. 검토 기록 해시가 바뀌면 추출 캐시를 새로 만든다. 검토하지 않은 짧은 페이지, 변경된 검토 이미지, 미검토 초안은 거부한다.

검증: API 테스트 23개 통과, 변경 Python 파일 Ruff 검사 통과. 로컬 mock 인덱스 검증 결과는 `data/retry-reports/vision/mock-audit.json`에 저장했다.

## 외부 임베딩 반영 완료

후속 사용자 요청에 따라 복원문을 설정된 외부 임베딩 API로 전송하고 실제 인덱스(`bab910f9b2a3551e`)를 갱신했다. 첫 네트워크 허용 실행에서 103개 게임이 성공하고 7개 게임이 API 호출 오류로 실패했으며, 캐시를 재사용한 후속 실행에서는 110개 게임 모두 성공했다. 최종 결과는 메타데이터 110개, 규칙 청크 2,541개, 실패 게임 0개다.

`data/retry-reports/vision/live-audit.json`에 최종 검증 결과를 저장했다. 모든 게임의 예상 청크 ID와 실제 인덱스가 일치하며, 추출 텍스트 오프셋·페이지 번호·벡터 차원·유한값 검사를 통과했다. 이 검증은 인덱스의 완전성과 구조를 확인하며, 위에 기록한 요약 전사 및 원문 모순의 한계를 없애지는 않는다.
