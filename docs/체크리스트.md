## 남은 과제

- **이용 조건(24번):** 공개 배포 전 규칙서별 재배포·임베딩 허가를 확인해야 한다. 허락되지 않은 문서는 색인에서 빼거나 출처 링크만 남긴다.
- **F2016 결합 사례:** 공식 FAQ·정오표와 규칙서의 검증된 관계가 아직 0건이다. 확보하면 `config/document-relations.json`에 등록하고 결합 결과를 기록한다.
- **T18:** SQLite 연결 실패를 재현하는 자동 테스트가 없다.
- **정확성 비교:** RAG 전후 비교에서 정확성 차이는 드러나지 않았다(널리 알려진 게임). 덜 알려진 게임으로 다시 비교할 필요가 있다.
